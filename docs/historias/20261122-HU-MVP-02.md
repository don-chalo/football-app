# HU-MVP-02: Visualización del MVP en el detalle del partido

**Como** usuario que consulta los detalles de un partido,
**quiero** que se muestre claramente quién fue el MVP (Most Valuable Player)
**para** que pueda consultar esta estadística clave de manera visible y directa en la ficha del partido.

## Reglas de negocio

- El MVP solo puede ser un jugador convocado al partido y no ausente.
- La visualización debe ocurrir únicamente si el partido está `finalizado` y existe un registro de MVP asociado.
- El distintivo “⭐ MVP” se debe mostrar al costado derecho del nombre del jugador MVP en la card "Convocatoria".

## Criterios de aceptación

### Criterio 1: Visualización exitosa del MVP
- **Dado** que el usuario consulta la página de detalle de un partido.
- **Cuando** el partido está finalizado y tiene un MVP registrado.
- **Entonces** se debe mostrar el distintivo de MVP junto al jugador MVP seleccionado.

### Criterio 2: Ausencia de MVP
- **Dado** que el usuario consulta la página de detalle de un partido.
- **Cuando** el partido está finalizado, pero no se ha registrado MVP.
- **Entonces** No se debe mostrar ningún distintivo.

### Criterio 3: Partido no finalizado
- **Dado** que el usuario consulta la página de detalle de un partido.
- **Cuando** el partido está programado, en curso o suspendido.
- **Entonces** No se debe mostrar ningún distintivo.

## Diseño funcional

- Se añadirá un componente reutilizable `MVPIndicator` que renderiza el snippet `<span className="font-bold text-energia-600"> ⭐ MVP</span>` cuando sea necesario.
- En `@acsed-web/src/pages/PartidoPage.tsx`, dentro de la *card* de convocatoria por equipos, el indicador debe aparecer junto al jugador que sea MVP.
- Actualmente la API del detalle del partido retorna `mvpJugadorId` y se debe comparar con cada jugador en la lista de convocados.
- El indicador debe integrarse visualmente con el resto de la card, siguiendo el estilo utilizado en `@acsed-web/src/components/CargaVivo.tsx`.

## Dependencias
- Dependerá de la funcionalidad `HU-MVP-01` que ya registra el MVP.
- Se debe incluir el componente `MVPIndicator` en el árbol de componentes.
